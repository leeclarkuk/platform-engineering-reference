# Alerts

Page on SLI burn, not on CPU averages. Examples:

* User-path 5xx burn rate (fast and slow)
* Latency p95 above SLO for a sustained window
* Argo CD Degraded for more than 15 minutes
* Certificate expiry inside 30 days
* VPN tunnel down _and_ packet test fail

If an alert has no owner, it is noise. Delete it.
