# Failure lab

A control plane reporting healthy does not prove that real application
traffic is healthy. This lab is how we test the user path.

Each experiment uses the same write-up. Fill **Observed** and **MTTR**
when you run it. Do not invent those numbers in Git.

Experiments live in `experiments/`. Run them in `dev` or a dedicated lab
account unless the write-up says otherwise.

Game days: pick three experiments, put them on a calendar, invite the
people who would be paged. Tabletop is not a substitute for injection.
