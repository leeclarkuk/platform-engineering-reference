# Runbooks

Runbooks for **this reference** live next to the thing they describe.
Application runbooks are generated by `platform create service` into
the service repo.

Platform runbooks to add as the foundations are applied:

| Symptom | First look | Owner |
| --- | --- | --- |
| Argo CD OutOfSync / Unknown | Application Git, then Argo CD app conditions | Platform if repo is fine |
| Image pull backoff | Registry identity, network path to ECR/ACR/AR | Platform if identity; app if tag |
| 5xx at ingress | Application `/ready`, then ingress, then DNS | App first |
| Hub packet drop | TGW/VNet route tables, NAT, firewall | Platform |
| OIDC CI failures | `sub` claim, role trust, clock skew | Platform |

A green control plane does not close a user-facing incident. Test the
user path.

Break-glass: Identity Center / Entra / Cloud Identity, time-bounded role,
ticket number in the session name.
